### 📂 주요 프로젝트

#### 🌬️ 서울시 AI 미세먼지 보건 분석 및 관제 시스템
- **지능형 분석 및 예측**: `YOLOv8` 기반 실시간 영상 객체 탐지 및 `RandomForest`를 활용한 지역별 미세먼지 위험도 예측 모델 구현
- **데이터 파이프라인 최적화**: `ThreadPoolExecutor`를 통한 API 병렬 수집으로 로딩 속도 70% 개선 및 `APScheduler` 기반 자동 갱신 체계 구축
- **AI 에이전트 서비스**: `Flask` 기반 모듈화 구조(Blueprint) 설계 및 `RunPod LLM API`를 연동한 지역 맞춤형 환경 정보 챗봇 개발
- **안전한 서비스 설계**: `Oracle DB` 기반의 캐싱 전략과 `Werkzeug`를 활용한 사용자 비밀번호 해싱 보안 처리 적용
